# ImageLab DXA — контроль качества денситометрии

Локальный сервис для DICOM-исследований поясничного отдела позвоночника и проксимального отдела бедра. Автоматически определяет область, получает анатомические ориентиры и выдаёт пять бинарных решений по измеряемым критериям. Работает на CPU; внешние сервисы при анализе снимков не используются.

**Веб-прототип:** https://app.betterimaging.ru/ — вход по учётным данным, выданным командой.

## Быстрый запуск

Требуются Linux x86_64, Docker, curl, tar и Python 3. Ориентир для сервера: 8 vCPU, 16 GB RAM, 10 GB для образа и ещё место под результаты. Это рекомендуемый ориентир, а не подтверждённый минимум.

```bash
git clone https://github.com/Ustalov/dxa_hackaton_lct.git
cd dxa_hackaton_lct
curl -fL --retry 3 https://github.com/Ustalov/dxa_hackaton_lct/releases/download/models-v1/dxa-runtime.tar.gz -o dxa-runtime.tar.gz
echo '75610644fe4c59c04414fda9420c87f039cb23548fa7198d0b9215cf350aef3f  dxa-runtime.tar.gz' | sha256sum --check
tar -xzf dxa-runtime.tar.gz
bash scripts/deploy/build.sh
bash scripts/deploy/run.sh
```

Открыть http://127.0.0.1:8095/; Swagger — http://127.0.0.1:8095/docs. При первом запуске задайте собственные логин и пароль. Пароль не включён в репозиторий или образ. `DXA_PORT=8096 bash scripts/deploy/run.sh` меняет порт. Перезапуск сохраняет результаты в `.runtime/jobs/`. Не запускайте несколько процессов Uvicorn на общей очереди.

Архив весов — отдельный актив релиза [models-v1](https://github.com/Ustalov/dxa_hackaton_lct/releases/tag/models-v1). Семь выбранных весов, конфигурации и служебный объект; SHA256 каждого файла — [манифест](docs/weights_manifest.json). Исходные DICOM и обучающие датасеты в комплект не включены.

## Использование

Загружайте только анонимизированные данные. Вход: DICOM, PNG, JPEG либо ZIP. Pixel Spacing по умолчанию X=0,6 / Y=1,05 мм/пиксель применяется ко всей загрузке; разные масштабы загружайте отдельно. Углы оси измеряются по квадратным пикселям, размеры — с указанным масштабом.

После обработки отображаются исходное изображение, разметка и нарушения. Для бедра — отступы и малый вертел; для позвоночника — ось и подвздошные контуры. Ссылки **XLSX** и **ZIP разметок** расположены над результатами каждой загрузки.

Общий класс — ИЛИ применимых нарушений. Если обязательная оценка недоступна на прочитанном снимке, назначается нарушение и сохраняется причина. Непрочитанный файл получает Failure без медицинского класса. Вероятность общего качества не рассчитывается. Проценты в интерфейсе — условная оценка уверенности, не влияют на решение.

## Структура и стек

`dxa/` — чтение DICOM, модели, измерения, API, экспорт; `web/prototype.html` — интерфейс; `scripts/deploy/` — сборка, запуск и проверка; `runtime-data/` — отдельно скачиваемые веса; `vendor/vertebra_landmark_detection/` — код ориентиров; `docs/`, `reports/`, `tests/` — документы, результаты и проверки.

Python 3.10, FastAPI/Uvicorn, PyTorch 2.5.1 CPU, segmentation-models-pytorch 0.5.0, NumPy/SciPy/OpenCV, pydicom, openpyxl. Базовые версии — requirements.txt; полный список проверенного контейнера — requirements.container.lock.txt. Развёртывание собирает образ, содержащий все модели; скачивание во время инференса не требуется.

Лицензии стороннего кода сохранены в vendor. Источники данных описаны в карточках моделей; права на исходные датасеты не передаются вместе с этим репозиторием.
