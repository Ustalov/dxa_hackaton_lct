# Сценарий демонстрации, 3–4 минуты

1. Показать задачу: пять видов нарушений, две анатомические области, локальная обработка.
2. Открыть прототип, выполнить вход. Показать напоминание об анонимизации и масштаб.
3. Загрузить анонимизированный контрольный снимок бедра: исходник, цветные рамки, малый вертел, решение и размеры.
4. Загрузить позвоночник: ось, угол и подвздошные контуры. Показать бинарные результаты.
5. Загрузить ZIP: обработка нескольких файлов, общий XLSX, ZIP визуализаций. Показать одну строку таблицы и связь с изображением.
6. Показать пример ошибки/недоступной оценки и отчёт расхождений; объяснить принятую политику.
7. Завершить результатами ретроспективной проверки и ограничениями. Не называть её закрытым независимым тестом.

Видео не создавалось. Для публичной демонстрации используйте только проверенные анонимизированные изображения. Собственные DICOM не вложены в публичный репозиторий.
