# Презентация

Создана на основе предоставленного шаблона ЛЦТ-2026. Обязательные блоки исходных слайдов 7–11 сохранены, заполнены технические разделы; далее добавлены архитектура, данные, результаты и ограничения. В публичной копии телефоны участников убраны; сохранены имена, роли и контакты Telegram из исходного шаблона.
